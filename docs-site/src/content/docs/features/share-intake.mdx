## How it works

Sharing to Bloom opens the [Capture picker](/features/capture) with the shared content already available to templates:

- The first shared **URL** becomes `%shared_url`; Bloom also fetches the page title in the background so a template can reference it (unless [Fetch link titles](#fetch-link-titles) is off)
- Any remaining shared **text** becomes `%shared_text`

Pick a template as normal; whichever placeholders it uses pull in the shared content automatically.

## Default target file

Settings → Sharing lets you set a **default target file** for shared content, so shares can land somewhere predictable even before you've built out a dedicated share-specific template.

## Fetch link titles

Settings → Sharing → **Fetch link titles** (on by default) controls whether Bloom looks up a shared link's web page to use its title as the note heading. Some sites only reveal their title after running a script, so for those Bloom loads the page in a hidden browser with JavaScript enabled.

Turn it off to keep sharing fully offline: Bloom makes no request. The link is still labeled with any title the sharing app includes (most browsers send one), otherwise with the URL itself.
